使用说明
  • 图片模式：在「内容」填图片直链（可放图床或自己的 R2），「点击链接」填跳转地址；留空则不可点击。
  • HTML 模式：粘贴联盟给的代码。支持异步脚本型（如 JuicyAds 的 <ins> + jads.js、Adsterra 的 container + 脚本）和 iframe / img 代码。
  • 不支持 document.write 型代码（如旧版 Adsterra atOptions 横幅），动态插入会清空整页；这类请用联盟后台的 iframe 版本。
  • 只勾选「启用」的位会显示；未启用的位自动隐藏，不留空白。保存后刷新首页（Ctrl+F5）即可看到。
  • 侧栏宽度约 208/224px，图片建议用自适应宽度，别放超过 300px 固定宽度的素材。
